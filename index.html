キャマイズ　スタジオ

キャマイズ　スタジオは、Camys（キャマイズ）がショート動画の運用を支援している店舗・企業・クリエイターの皆さまのためのサービスです。

できること

  • ご自身のTikTok・Instagram・YouTubeのアカウントを、各サービス公式のログイン機能で連携できます。
  • 制作したショート動画を、予約した日時に各サービスへ届けます。
  • TikTok：予約した日時に、アカウントの持ち主が選んだ公開範囲・コメント等の許可・商用コンテンツの開示のとおりに直接投稿します（TikTok公式の Content Posting API を使用）。投稿前に、投稿先のアカウント名を表示して確認できます。
  • Instagram：リールとして予約した日時に公開します（Instagram公式のAPIを使用）。
  • YouTube：動画をアップロードし、予約した日時に公開します（YouTube Data API を使用）。

連携の解除

  • TikTok：アプリの「設定とプライバシー」→「セキュリティと権限」→「アプリとサービスの権限」
  • Instagram：アプリの「設定とアクティビティ」→「ウェブサイトのアクセス許可」→「アプリとウェブサイト」
  • YouTube：Googleアカウントの「セキュリティ」→「サードパーティ製のアプリとサービスへの接続」

上記からいつでも連携を解除できます（各アプリの画面の名前は変わることがあります）。

お問い合わせは、運営者の担当窓口までご連絡ください。

About (English)

Camys Studio is a scheduling service for the stores, companies and creators whose short-form videos are produced by Camys. Each user connects their own TikTok, Instagram and YouTube accounts through each platform's official login, and schedules videos to be posted at a chosen date and time.

  • TikTok: before scheduling, the user sees the connected account's nickname, chooses the privacy level (no default), allows comments / duet / stitch (off by default), discloses commercial content if needed, and agrees to TikTok's Music Usage Confirmation. The video is then posted directly via the TikTok Content Posting API.
  • Instagram: published as a Reel at the scheduled time (Instagram API).
  • YouTube: uploaded and published at the scheduled time (YouTube Data API).

Users can disconnect at any time from each platform's app settings.
